# Asset production

Bulk assets wait for an approved camera/rendering proof and style guide.
Proposed packs: cars, road surfaces and lane markings, biome ground tiles,
vegetation, skyline layers, landmark props, cones and barriers, UI, story,
music stems/sound banks, radio voice and captions.

Every pack needs a versioned manifest: asset ID, region/state tags, dimensions,
pivot, scale, atlas coordinates, collision footprint (separate from visible
sprite), lighting/palette reference, source/license, generation prompt/reference
where applicable, and memory budget. No generated imagery is commissioned yet.

## Current original/provided assets

- Garage/key/car and racing visuals are original procedural Canvas compositions
  in lib/ui/painters.dart and lib/game/race_game.dart. They are a first playable
  visual pass, not approved final raster sprite sheets.
- WebAudio note patterns/arrangements are original in web/platform_bridge.js
  and remain the fallback when prepared audio cannot load.
- Noto Sans variable font: assets/fonts/NotoSans.ttf, from Fedora's
  google-noto-vf package (upstream Google Noto). SIL Open Font License retained
  in assets/fonts/OFL.txt. It is bundled so core UI does not need a font CDN.
- The user explicitly selected the white roof-off 2019 Stingray as the final
  car reference; its procedural representation is not a sourced GM photograph.

## Scenic library (`assets/scenic/`)

Generated by the local asset pipeline (`art/README.md`; spec:
`openspec/changes/scenic-depth-asset-pipeline/`). Never edit by hand:
`go run -C tool/assets . pack` rebuilds `assets/scenic/*.png` atlases,
`assets/scenic/road/*.png` tileable textures and `assets/scenic/manifest.json`
(`scenic-1`: sprite rects, anchors, real widths in metres, depth band, kind,
biomes, frames, sway) byte-identically from the committed picks in
`art/sources/<family>/`. Provenance per pick (workflow, models with
repo@revision and licence, prompt, seed, hashes, pick reason) is in
`art/families/<family>-runs.json`; model licences in `licences/register.md`.
Picks were made by agents under the user's 2026-11-20 approval and are review
material the user can override; physical-phone review is still open. Budget:
atlases + textures <= 16 MB, committed picks <= 60 MB (`... check`).

## Audio (`assets/audio/`)

- `catalog.json` (version 1): legacy keys `tracks` (three synthesized score
  studies), `radio` (Kokoro state-derived reports keyed by exact text) and
  `surf` stay readable; the `programme` block adds the radio programme:
  `stations` (id, name, frequency, genres, regions), `songs`, `buzz`,
  `interjections` and sequencing `rules`. Older players ignore it.
- `music/<song>.mp3`: wordless ACE-Step 1.5 songs (MP3 192 kbps, 48 kHz
  stereo, -16 LUFS, <= -1 dBTP), `music/dj-*.mp3` presenter lines (Kokoro,
  radio band, mono 96 kbps), `music/buzz-*.mp3` synthesized tuning sweeps.
  Specs, workflow, render/pick log and the 3-step recipe: `art/music/README.md`.
  Tools: `tool/audio/radiokit` (Go) and `tool/audio/interjections.py`.
- `radio-verification.json`: decoded loudness/true-peak/duration/bitrate per
  programme file and the audio budget (<= 120 MB for `assets/audio/`).
- Songs stream through one `<audio>` element (never fully decoded); see
  `web/radio_programme.js`. Never edit generated audio by hand.
